This uses your browser's built-in voices (Web Speech API). Voice quality depends on your device and browser.

How it works

Static GitHub Pages can't run a model or hold a key. So the demo above runs entirely in your browser — and the neural version runs server-side in a Space. Two engines, same separation of concerns.

  • In-browser: Web Speech API — zero backend, zero key, works offline
  • Neural Space: free Edge TTS on Hugging Face — consistent voices for every visitor
  • Optional premium ElevenLabs engine if a key is set as a Space secret
  • English, French & Spanish across both
Visitor opens /demo/ (static)
  -> [now] browser Web Speech API
     (audio synthesized on-device)
  -> [neural] embedded Hugging Face Space
     -> free Edge TTS (no key)
        [optional: ElevenLabs if a key]
  -> audio playback (EN / FR / ES)
