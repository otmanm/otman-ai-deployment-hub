Voice Demo

A small Hugging Face Space proves the voice layer: text in, ElevenLabs audio out, API keys stored as private Space secrets.

Live demo target

When deployed to Hugging Face, the Space lets a visitor generate a short voice response for a consulting website assistant.

Open Hugging Face Spaces

What is included

  • `spaces/voice-demo/app.py` with a Gradio interface
  • ElevenLabs text-to-speech integration
  • Safe missing-key fallback
  • Deployment guide for Hugging Face Spaces
  • Optional future OpenAI answer generation hook

Deployment path

This is deliberately small enough to inspect in minutes and real enough to show API deployment competence.

Gradio UI
  -> visitor text
  -> ElevenLabs API
  -> generated audio
  -> browser playback
  -> contact CTA
