Voice Demo

Type a short script, pick a language, and hear it back. The demo runs in a Hugging Face Space using a free, open neural voice — no API key — in English, French, and Spanish. Premium ElevenLabs voices are optional. The website itself holds no keys and runs no model.

The Space sleeps after inactivity on free hardware — the first load can take 20–40 seconds to wake. If the demo does not appear, open the full demo on Hugging Face.

How it works

GitHub Pages is static, so it cannot run a model or hold a key. The browser talks to the Space; the Space does the work server-side.

  • Gradio app in spaces/voice-demo/app.py
  • Free, open neural voice (Edge TTS) — no API key, no cost
  • English, French & Spanish out of the box
  • Optional premium ElevenLabs engine if a key is set as a Space secret
This page (GitHub Pages, static)
  -> iframe embeds the Space
  -> Hugging Face Space (Gradio, Python)
  -> free Edge TTS engine (no key)
     [optional: ElevenLabs if a key is set]
  -> generated audio (EN / FR / ES)
  -> playback inside the embed
